# Harshal Kalavadiya Portfolio

Modern React + Vite portfolio for Harshal Kalavadiya, Mobile Application Tech Lead.

## Stack

- React 19 + Vite 7
- Framer Motion (scroll & entrance animations)
- Lucide React (icons)
- Sass

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Content & links

Resume data, LinkedIn, GitHub, email, phone, and resume download URL are sourced from the existing portfolio at [harshal-kalavadiya-portfolio](https://harshal-kalavadiya-portfolio--harshalkalavadi.replit.app/).
